# NEXORA: DEADFALL

**NEXORA: DEADFALL** is a mature-rated zombie survival shooter for Android, built with Godot 4. The project targets a shared gameplay simulation for offline play and authoritative dedicated-server multiplayer.

## Project status

Pre-production / technical bootstrap.

Current foundation goals:

- Android-first, landscape 3D gameplay.
- First-person and third-person camera modes.
- Campaign, standard matches and endless horde.
- Offline solo/bots and online co-op for 2–4 players.
- Server-authoritative combat, damage, zombie AI and match state.
- Limb-based damage, ragdolls and scalable gore budgets.
- Performance tiers from low-end Android devices to high-end devices.
- Dedicated Ubuntu/VPS server deployment.
- Automated validation and build checks with GitHub Actions.

## Engine baseline

The repository is currently pinned to **Godot 4.6.3 stable** for reproducible development and CI. Engine upgrades must be intentional and documented.
